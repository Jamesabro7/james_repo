# Фирменный стиль презентаций (ASRR)

## Настройка (заполняется пользователем)

При первом использовании спроси и зафиксируй здесь (или в файле
`brand/config.md` рабочей папки) реальные значения; пока действуют дефолты:

- Основной цвет: `#1B5E9E` (гос-синий) — заголовки, акценты
- Дополнительный: `#2E8B57` (зелёный) — позитивная динамика, «выполнено»
- Сигнальные: `#C0392B` (красный — риск/невыполнено), `#E67E22` (оранжевый — внимание)
- Фон: белый; текст: `#1A1A2E`
- Шрифты: заголовки — жирный без засечек (Arial/Inter), текст — тот же, минимум 18 pt в pptx
- Логотип/герб: путь к файлу — уточнить у пользователя

## Структура типового доклада руководству

1. **Титул:** тема, докладчик, дата. Ничего лишнего.
2. **Главный слайд («суть за 30 секунд»):** 3–4 ключевые цифры крупно +
   один вывод. Руководитель может не досмотреть остальное.
3. **Состояние:** факт против плана, светофор (🟢🟡🔴), динамика к прошлому
   периоду.
4. **Проблемы:** каждая проблема = что случилось + чем грозит + что предлагаем.
   Проблема без предложения на слайд не выносится.
5. **Предложения / требуемые решения:** пронумерованные, каждое — с
   исполнителем и сроком.
6. Приложения — детальные таблицы (на случай вопросов, не для показа).

## Правила подачи

- Один слайд — одна мысль. Заголовок слайда — вывод, а не тема:
  не «Динамика показателей», а «7 из 12 показателей отстают от плана».
- Максимум 5 строк текста на слайде; всё, что длиннее, — в раздатку.
- Цифры: крупно, с единицами измерения, с базой сравнения (к чему %).
- Графики строй по скиллу dataviz (если доступен): подписанные оси,
  необрезанный ноль у столбцов, не более 6 категорий в легенде.
- Светофорные статусы — только по явным порогам (например: 🟢 ≥ 90% плана,
  🟡 70–89%, 🔴 < 70%); пороги показать в сноске.
- Двуязычность: если аудитория смешанная — заголовки на узбекском, при
  необходимости дубль на русском мелче; язык согласуй с пользователем.

## Форматы

- **pptx** — через скилл pptx (основной формат для совещаний);
- **HTML-дашборд** — самодостаточный файл, тёмный/светлый режим, крупные
  KPI-карточки сверху, детальные таблицы ниже;
- **PDF** — печатная версия через скилл pdf.
