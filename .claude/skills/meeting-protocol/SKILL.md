# Протокол совещания

## Порядок работы

1. **Собери недостающее.** Если во входных данных нет — спроси одним списком:
   название органа/совещания, дата и место, номер протокола, председатель
   (раис), секретарь (котиб), список участников, язык документа
   (узбекский кириллица/латиница или русский).
2. **Извлеки из заметок:** вопросы повестки, кто выступал и суть выступлений,
   принятые решения, поручения (кому, что, срок).
3. **Собери протокол по формуляру** (см. ниже).
4. **Проверь поручения:** у каждого поручения должны быть исполнитель и срок.
   Если срок не прозвучал — пометь `[СРОК?]` и спроси пользователя, не выдумывай.
5. **Предложи разнести поручения по GTD:** поручения пользователя →
   `gtd/next-actions.md` или `projects.md`; поручения другим →
   `gtd/waiting.md` (кто, что, срок, номер протокола).
6. Финальную вычитку языка делай по скиллу uzbek-grammar (для узбекского),
   оформление под Word — по gov-doc-copywriter.

## Формуляр протокола

```
[НАИМЕНОВАНИЕ ОРГАНА]

[КЕНГАШ / МАЖЛИС] БАЁННОМАСИ / ПРОТОКОЛ № ___

[Дата]                                                    [Место]

Раислик қилувчи / Председательствовал: [Ф.И.О., должность]
Котиб / Секретарь: [Ф.И.О.]
Қатнашдилар / Присутствовали: [список или «___ киши, рўйхат иловада»]

КУН ТАРТИБИ / ПОВЕСТКА ДНЯ:
1. [Вопрос 1] — докладчик [Ф.И.О.]
2. ...

1-МАСАЛА ЮЗАСИДАН / ПО ПЕРВОМУ ВОПРОСУ:
ЭШИТИЛДИ / СЛУШАЛИ: [кто, краткое содержание]
СЎЗГА ЧИҚДИЛАР / ВЫСТУПИЛИ: [кто, суть]
ҚАРОР ҚИЛИНДИ / РЕШИЛИ:
1.1. [Решение / поручение] — масъул: [исполнитель], муддат: [срок].
1.2. ...

Раислик қилувчи: _________ [Ф.И.О.]
Котиб: _________ [Ф.И.О.]
```

## Правила формулировок решений

- Решения — в форме на -sin/-илсин (узб.) или инфинитив/«поручить» (рус.):
  «ijro etilsin», «nazorat qilinsin», «маълумот учун қабул қилинсин»;
  «принять к сведению», «обеспечить исполнение до …».
- Одно решение — одно поручение — один ответственный. Если ответственных
  несколько, первый — главный (масъул), остальные — «биргаликда».
- Контроль исполнения — отдельным последним пунктом: на кого возложен.

## В конце всегда выдай сводку поручений

Таблица: № пункта | поручение | ответственный | срок | занесено в GTD (да/нет).
