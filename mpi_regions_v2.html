Как считается индекс

Метод Мацциотты — Парето, который применяет статистическая служба Италии (Istat), в двухшаговом варианте.

Собираем показатели

28 удельных показателей по каждому региону: по 4 в каждом из 7 доменов. Для каждого задана полярность — рост показателя это хорошо или плохо. Значения за пределами 5-го и 95-го перцентилей ограничиваются (винзоризация).

Приводим к одной шкале

Каждый показатель пересчитывается так, чтобы среднее по стране равнялось 100, а стандартное отклонение — 10. «Плохие» показатели переворачиваются.

z = 100 ± 10 · (x − M) / S

Считаем домены

Внутри домена берётся среднее четырёх оценок и вычитается штраф за разброс между ними. Получается субиндекс домена.

MPI = M − S² / M

Сводим в итог

По той же формуле из семи субиндексов получается итоговый MPI. Каждый домен весит одинаково — по 14,3 %, а перекос между доменами снова штрафуется.

Пример: г. Ташкент

Среднее семи субиндексов — 108,48, разброс между ними — 10,12. Штраф равен S² / M = 10,12² / 108,48 = 0,94 балла. Чем ровнее развитие по доменам, тем меньше штраф и тем ближе итог к простому среднему.
